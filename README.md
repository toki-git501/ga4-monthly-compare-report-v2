# GA4 月次比較レポート v2

歯科医院向けに、GA4のエクスポートCSV（当月・前月）から月次比較PDFを生成するStreamlitアプリ。

**本番**: https://ga4-monthly-compare-report-v2.streamlit.app/
**現行バージョン**: `2026-10-13-v9`

---

## AIエージェント・開発者の方へ

作業前に **[AGENTS.md](./AGENTS.md)** を全文お読みください。
過去に本番でクライアントに誤った情報を出していた箇所と、その修正理由が書かれています。
リファクタで元に戻さないよう、テストで固定しています。

## 使い方

1. GA4で、同じ期間を指定して次のCSVをエクスポート（当月分・前月分それぞれ）
   - 「レポートのスナップショット」
   - 「レポート > 集客 > 集客サマリー」
   - 「レポート > エンゲージメント > 概要」
   - （任意）「レポート > エンゲージメント > イベント」
2. 上記URLの「当月のCSV」「比較したい月のCSV」に、それぞれ同じ月のファイルをまとめて選択
   （1〜4ファイル。旧形式のスナップショット1ファイルだけでも動きます）
3. 標準版（9ページ）または詳細版（11ページ）を選んでPDFを生成

比較月のCSVを指定しない場合は単月モードになります。

2026-10以降、GA4「レポートのスナップショット」には日別アクティブユーザー・日別新規ユーザー・
平均エンゲージメント時間・30/7/1日アクティブユーザーが含まれなくなりました。
必要項目が不足している場合は、空白や0件を含む誤ったPDFを生成せず、
不足項目ごとに「GA4のどの画面から出力すればよいか」を画面に表示して停止します。
同じセット内でプロパティや期間が異なるファイルが混ざっている場合も、ファイル名を示して停止します。
同じ表が複数のファイルにあって値が食い違う場合（一方が見出しだけの場合を含む）、数値の欄が「-」・空欄の場合、
日別の表に期間内の日が欠けている場合、プロパティ名が空の場合も停止します
（内容が完全に同じファイルを二重に指定した場合は2つ目以降を読み込まず、画面に注意を出します）。
暦月でない期間（例 9/15〜10/12）は月名ではなく期間で表示します。

### 予約・電話アクションの合計に含めないもの（v9〜）

- 外部の予約サイト等の**完了画面への到達**（イベント名の末尾が「_完了」「_complete」「_thanks」等で、
  対応するクリックのイベントが同じ月にあるもの）。予約成立数ではなく、クリックの後の段階のため、
  P4右の別表に分けて示します。対応するクリックが無い場合は唯一の計測として合計に含め、注記します
  （イベント名から判定した月は、予約・電話等の語を含む場合に限ります）
- **件数・総ユーザー数とも同じ2つのイベント**（共通の先頭を持ち、各20件以上・10人以上のもの）。
  同じ操作を2つのイベントで数えている可能性があるため、合計には1つ分のみ含め、もう一方は表に
  「同数のため合計から除外」と残します。総ユーザー数（キーイベント明細の月はイベント数も）は
  「イベント」レポートのCSVから読むため、このCSVが無い月は除外せず注記のみです
  （無効化: `event_classify.DEDUPE_SAME_COUNT_EVENTS = False`）
- 上記の除外・別掲の扱いが当月と前月で食い違うイベントがある場合は、合計・小計の前月比を
  「比較不能」とし、理由を注記します（当月・前月の値は表示します）
- イベント名から判定した月で、予約・電話等と判定できなかった**未分類のイベント**
- **求人関連**のイベント（従来どおり別集計）

## 開発

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt pytest pdfplumber

.venv/bin/python -m pytest tests/ -q   # テスト195件
.venv/bin/streamlit run app.py          # ローカル起動
```

`main` への push で Streamlit Community Cloud が自動再デプロイします。
**反映されたかは画面フッターまたは生成PDF11ページ目のバージョン表記で確認してください。**
push しただけでは確認したことになりません（実際に旧コードが配信され続けた事例あり）。

## このアプリが出せないもの

入力がGA4スナップショットCSVのみのため、以下は**構造的に算出できません**。
推定で埋めず「取得不能」と表示しています。

- 暦月のユニークユーザー数（30日ローリングの期間末値で代用・注記あり）
- 広告経由のCV・CVR・CPA・ROAS（広告費がCSVに含まれない）
- ページ別の実測滞在時間（PV按分の推定値のみ）
- 検索順位・検索クエリ（Search Consoleが必要）
- フォームの離脱箇所
- キーイベントのイベント別内訳（新形式のスナップショットには含まれない）。
  「エンゲージメントの概要」または「イベント」のCSVがある場合に限り、イベント名から予約・電話等の
  候補を判定して「イベント名から判定」と注記します。GA4のキーイベント明細とは集計方法が異なるため、
  明細の月とは前月比較しません。求人関連のイベント（求人応募ボタン・求人サイトへのリンク等）は
  計測しますが、予約・電話アクションの合計には含めず別集計（P4右の別表）で表示します
- 海外アクセスの混入有無（「国」セクションが無く「市区町村」だけのCSVでは判定できません）
