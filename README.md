# GA4 月次比較レポート v2

歯科医院向けに、GA4の「レポートのスナップショット」エクスポートCSV（当月・前月の2ファイル）から
月次比較PDFを生成するStreamlitアプリ。

**本番**: https://ga4-monthly-compare-report-v2.streamlit.app/
**現行バージョン**: `2026-09-14-v5`

---

## AIエージェント・開発者の方へ

作業前に **[AGENTS.md](./AGENTS.md)** を全文お読みください。
過去に本番でクライアントに誤った情報を出していた箇所と、その修正理由が書かれています。
リファクタで元に戻さないよう、テストで固定しています。

## 使い方

1. GA4で「レポートのスナップショット」をCSVエクスポート（当月分・前月分）
2. 上記URLで2つのCSVをアップロード
3. 標準版（9ページ）または詳細版（11ページ）を選んでPDFを生成

比較月のCSVを指定しない場合は単月モードになります。

「集客サマリー」など、必要項目が不足したCSVをアップロードした場合は、
空白や0件を含む誤ったPDFを生成せず、再出力手順を画面に表示して停止します。

## 開発

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt pytest pdfplumber

.venv/bin/python -m pytest tests/ -q   # テスト45件
.venv/bin/streamlit run app.py          # ローカル起動
```

`main` への push で Streamlit Community Cloud が自動再デプロイします。
**反映されたかは画面フッターまたは生成PDF11ページ目のバージョン表記で確認してください。**
push しただけでは確認したことになりません（実際に旧コードが配信され続けた事例あり）。

## このアプリが出せないもの

入力がGA4スナップショットCSVのみのため、以下は**構造的に算出できません**。
推定で埋めず「取得不能」と表示しています。

- 暦月のユニークユーザー数（30日ローリングの期間末値で代用・注記あり）
- 広告経由のCV・CVR・CPA・ROAS（広告費がCSVに含まれない）
- ページ別の実測滞在時間（PV按分の推定値のみ）
- 検索順位・検索クエリ（Search Consoleが必要）
- フォームの離脱箇所
